Clip Engine

A private tool that helps one YouTube channel learn from its own results.

Clip Engine is used only by the owner of the channel it serves. With the owner's permission, it reads that channel's YouTube Analytics reports (views, watch time, subscribers gained, audience countries and traffic sources) so it can judge which videos work and improve the next ones.

It is not a public service, it does not offer accounts to anyone else, and it never posts, edits or deletes anything on YouTube through this sign-in. Access is read-only.
